# Capturas canónicas del TFM

Guardar aquí únicamente capturas reales del producto ejecutado en modo demo/anónimo cuando corresponda.

Nombres obligatorios:

```text

02_team_mode.png
03_player_mode.png
04_match_mode.png
05_gps.png
06_attention.png
07_coach_copilot.png
08_pdf_team.png
09_pdf_player.png

```

Reglas:

- usar `FPS_DEMO_MODE=1` para las vistas con datos;
- mostrar `Equipo Demo`, `Jugador XX` y `Rival XX`, no identidades profesionales reales;
- no mostrar API keys;
- no mostrar rutas locales privadas;
- no presentar fatiga, lesión, XI o táctica como claims validados;
- en `07_coach_copilot.png`, abrir `Evidencia consultada` y preferir una consulta determinista que muestre `LLM utilizado: no`;
- mantener resolución y escala visual coherentes entre capturas.

Launcher recomendado antes de capturar:

```powershell
.\run_final_demo.ps1
```
