# Football Performance System

> Repositori principal del TFM: sistema funcional de suport a la decisió per a equips de futbol amateur o semiprofessional sense departament d’anàlisi.

Aquest projecte transforma dades simples de vídeo i GPS opcional en informació estructurada per al cos tècnic mitjançant una arquitectura separada per capes:

```text
COLLECTOR + GPS opcional
→ DATABASE
→ FEATURE ENGINE
→ ANALYTICS
→ EXPERT SYSTEM / ML
→ WEB DASHBOARD
→ ASSISTANT IA
→ PDF / informes
```

La web és el producte principal. Els PDF són exportacions estàtiques complementàries.

Consulta `PROJECT_STATE.md` per a l’estat tècnic actual, decisions aprovades, experiments, limitacions i següent pas exacte.
